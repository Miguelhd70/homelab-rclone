Homelab Rclone

Aplicación de uso privado para gestionar copias de seguridad de sistemas domésticos mediante rclone y Google Drive.

Finalidad

La aplicación permite transferir copias de seguridad desde un servidor privado a una cuenta personal de Google Drive.

Privacidad

Los datos se utilizan exclusivamente para las copias de seguridad del propietario. No se venden ni se comparten con terceros.
